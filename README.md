# deleg8-website

Marketing site and waitlist for **deleg8**, a company that sets up AI junior employees for engineering teams.

This repo is also the **workplace** for deleg8's own AI junior engineer, "Dex". Work arrives as GitHub Issues
(epics, stories and bugs labelled `deleg8`). Dex plans the work, opens PRs, and CI/CD ships it.

- Live (static snapshot): https://attrivivekai.github.io/deleg8-website/
- Image: `ghcr.io/attrivivekai/deleg8-website:latest`
- Harness: https://github.com/attrivivekai/deleg8

See [AGENTS.md](AGENTS.md) for commands and conventions, and [docs/](docs/) for the engineering wiki.
